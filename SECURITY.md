# Security Policy

## Reporting a vulnerability

Send a private report to the maintainers rather than opening a public issue. Include the
affected route, reproduction steps, and any relevant request or log excerpts.

We aim to acknowledge reports within two business days and to ship a fix or mitigation for
confirmed issues within ten business days.

## Scope

The portal handles fictional patient records in local and staging environments. Production
access is limited to authorized care team members. Do not include real patient information
in issues, pull requests, or test fixtures.

## Supported versions

Security fixes are applied to the current release line.
